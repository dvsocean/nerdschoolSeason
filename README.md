# Nerdschool Season

Nerdschool helps beginners learn how to build software on the computer they already use. We work through small, practical examples so you can see what each tool does, check your work, and figure out what happened when something goes wrong.

AI is part of how we learn. Use it to ask questions and explore ideas, then try things yourself and check the results. The goal is to understand your work well enough to explain it and make your own decisions.

This repository holds a few C# examples and gives you a place to practice cloning a project and reading its history with Git.
